# Réglages ATV et Mobile

Les contrôles proviennent du bundle public de https://nuvio.tv/account (page-09c8c711fef692db.js), consulté le 14 septembre 2026 : 153 champs ATV et 148 Mobile. Deux contrôles supplémentaires proviennent de NuvioMobile : NavBarStyle.kt et MetaScreenSettingsRepository.kt. Les libellés français proviennent des ressources values-fr des applications, avec corrections de contexte.

Les valeurs inconnues sont conservées et proposées comme valeurs actuelles. Les identifiants techniques restent visibles pour le diagnostic. Les contrôles conditionnels du site sont tous accessibles ; les restrictions Supporter restent appliquées par Nuvio. Les données avancées sans formulaire officiel restent éditables en JSON. Aucun ajout ni changement n’est envoyé avant aperçu et confirmation.

Les blocs Mobile encodés en JSON conservent leur format, les champs inconnus et les types. Les noms d’addons/plugins sont les valeurs des sélections multiples, conformément au site officiel.
